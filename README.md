# Фильтрация критичных событий

Скрипт читает восемь событий из `events.json`, отфильтровывает шум и
выводит только события с уровнем `critical`.
После списка он печатает итоговую строку с числом критичных событий.

## Запуск

Требуется Node.js с поддержкой ES-модулей и JSON import attributes (рекомендуется
Node.js 20.10+).

```bash
node script.js
```

## Результат

Входной файл содержит восемь событий уровней `info`, `warn` и `critical`.
Скрипт использует `filter`, поэтому в консоль попадают только три критичных
события:

```text
disk 90%
payment failed
db timeout
Summary: критичных событий: 3
```

Информационные и предупреждающие события не попадают в вывод.
Итоговая строка показывает их количество после фильтрации.
